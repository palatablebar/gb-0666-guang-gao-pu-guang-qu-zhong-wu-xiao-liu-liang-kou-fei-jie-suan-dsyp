# 广告曝光有效性与费用结算数据定义

原始行=采信事件+无效曝光+重复回调+其他隔离+空行。原始费用-合法扣减=应付。CPM单位为CNY/千次，先按渠道和北京时间账日求和，再HALF_UP舍入到分。扣减额采用原始舍入总额与净额之差，保证分币守恒。机器事件优先于频次，机器事件不消耗频次；频次按渠道、账日、用户计数。冲销事件本身不计曝光，不占频次，须不早于原事件且渠道相同。ID保留为字符串。

按曝光ID裁决重复与冲突，按时间及ID确定日频次，再聚合有效CPM。冲销引用采信的原曝光，同一曝光最多冲销一次，费用回到原曝光账日。

原始行号对应 CSV 解析器的物理末行。UTF-8 BOM 与 GB18030 均支持，坏行进入隔离区，结构性错误返回422。空文件、仅表头和全空记录分别返回不同原因码。金额与用量使用 Decimal，对外以字符串返回。编码和编号按字符串保留。

run_id 由输入摘要、参数和规则版本生成；revision 为人工复核版本。证据 CSV 含运行号、来源行、原因码、原始字段及最终结论。

## 账期裁决（M8）

账期按北京时间账日的 YYYY-MM 划分。关账对已发布运行生成只读快照（period_closures 表）：冻结逐渠道原始费用、扣减、应付与采信曝光ID，此后原账期任何数值不再回写，历史运行与快照长期可查。

补交批次（supplement_runs 表）经 M1-M3 同一套采信、契约、有效性流水线后按账期裁决：账日属于关账期的采信曝光为迟到曝光，引用关账期或迟到曝光的合法冲销为迟到冲销，二者差额按渠道先聚合后 HALF_UP 舍入，全部计入当前账期，不回写原账期、不挂账。本次正式应付＝本期自身净额＋关账期差额（逐渠道分别舍入后求和），金额守恒为 本期净额＋差额＝应付。

supplement_id 由补交内容、关账账期、当前账期与关账摘要的 SHA256 生成；同批重试命中 UNIQUE 摘要只返回同一条记录，不新增待复核版本。裁决异常在写入前抛出并整体回滚，旧版本保持不变。重复补报 LATE_DUPLICATE、重复冲销 OVER_REVERSE、跨渠道 CHANNEL、冲销早于曝光 REVERSE_TIME、无效引用 REFERENCE、账期外 OUT_OF_PERIOD 进入隔离并保留来源行；机器与超限曝光保留在 invalid，均不产生金额。行数守恒口径：采信行（含被账期裁决隔离的行）＋无效曝光＋流水线隔离＋空行＝输入原始行。
